## Applied changes

* Reserved front matter: Page methods replace deprecated direct lookups for title, description, and link title. A shared helper preserves explicit-field absence, original home/untitled-title output, overview-label fallbacks, and custom params overrides. No public configuration was added.
* Diagnostics: fixture builds use info log level and reject INFO deprecated messages. Existing expected navigation warnings remain explicit; ordinary info output is allowed. Unit and fixture regression checks cover both detection and rendered values.
* CI: all four actions-hugo steps select standard Hugo. YAML and workflow static checks pass. The standard-Hugo CI change is published as a dedicated PR; its hosted quickstart check passed.
* Guidance: release-note generation reads both canonical Hugo requirements and no longer inserts a historical SASS breaking-change claim into every release. The documentation contributor reference now uses standard Hugo.
* User documentation: troubleshooting explains default HTML/Org denial, narrow opt-ins for trusted project content, and removal of the extended edition. No security policy or support declaration was loosened.

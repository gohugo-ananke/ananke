# Shortcode changes

* Accept both named and positional parameters; use `IsNamedParams` to distinguish them.
* Use `InnerDeindent` for inner content.
* Access page and site variables through `.Page` and `.Site` from the shortcode context.
* Follow the translation rules in `templates.instructions.md`.
* Update the separate documentation repository for new or changed shortcode features.

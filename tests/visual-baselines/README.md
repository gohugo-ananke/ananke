The browser job passed 106 interaction/accessibility tests and generated 12 screenshots in `mcr.microsoft.com/playwright:v1.65.1-noble`. Capture uses UTC, `en-GB`, reduced motion, a fixed clock, disabled animations, and loaded fonts.

The initial images have been inspected by the assistant and are included for human review in the pull request. This is not a completed human accessibility or screen-reader review. Follow [the manual testing guide](../manual-tests.md) when approving or replacing baselines.
